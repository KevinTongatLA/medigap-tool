# Medigap Behavioral & 25-Year Cost Profiler

An interactive, single-page web assessment tool designed to help individuals select the optimal Medicare Supplement (Medigap) plan based on behavioral risk tolerance and long-term financial modeling.

---

## 🌟 Key Features

* **Dual-Angle Behavioral Profiling:** 20 cross-examination questions testing 10 psychological domains from two distinct perspectives to ensure score consistency.
* **Discrepancy Auto-Adjustment:** Automatically flags conflicting responses (e.g., high risk tolerance vs. care-seeking hesitation) and adjusts recommendations for medical safety.
* **Itemized 25-Year Financial Breakdown (Age 65–90):** Clearly separates mandatory Medicare Costs (Part A/B) from Medigap Premiums and Out-of-Pocket Usage (copays/deductibles).
* **Mobile & Print Friendly:** Fully responsive on iOS/Android and formatted for clean PDF report exports.
